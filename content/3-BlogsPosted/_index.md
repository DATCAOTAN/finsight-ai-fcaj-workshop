Below is a list of technical blogs I have written and shared on the [AWS Study Group](https://www.facebook.com/groups/awsstudygroupfcj) community. Instead of solely sharing personal projects, these posts are synthesized from my research into deep-dive articles on the official AWS Blogs, summarizing core concepts for the tech community.

### [Blog 1 - Lightning-fast AWS Lambda Startups with SnapStart](3.1-Blog1/)
A summary and review of the solution to AWS Lambda's notorious cold-start latency. The post explains how SnapStart uses microVM snapshots to speed up function execution by up to 10x, making it highly beneficial for Java, Python, and .NET environments.

### [Blog 2 - Amazon S3 Express One Zone - Hyper-fast Storage for Database and Analytics](3.2-Blog2/)
Referencing Turso's case study on the AWS Storage Blog, this post analyzes why a Storage Class like S3 Express One Zone, with single-digit millisecond latency, can be utilized as a durability layer for demanding transactional databases.

### [Blog 3 - Vector Databases on AWS - The Heart of Generative AI (RAG) Applications](3.3-Blog3/)
A knowledge synthesis from the AWS Big Data Blog regarding the critical role of Vector Databases in the AI era. The post explains the RAG (Retrieval-Augmented Generation) mechanism and highlights top vector storage solutions on AWS, such as OpenSearch, pgvector, and Bedrock Knowledge Bases.
